# e-plantShopping

## Paradise Nursery – Houseplant Shopping Application

**e-plantShopping** is a simple shopping application for houseplants called **Paradise Nursery**. The app allows users to browse a collection of houseplants, add them to a shopping cart, and manage the items before checkout.

This project is designed as a practice project to help build the skills required for a final project. Many of the components, code structures, and concepts used here can be reused and extended in the final project with some improvements.

---

## Project Overview

The **Paradise Nursery** application provides a simple and user-friendly interface for shopping houseplants. Users can:

- Browse different houseplants
- View plant details and prices
- Add plants to a shopping cart
- Adjust quantities of items in the cart
- View the total cost before checkout

The application consists of **three main pages**:

1. Landing Page  
2. Product Listing Page  
3. Shopping Cart Page

---

## Application Pages

### Landing Page

The landing page introduces the Paradise Nursery store and provides navigation to start shopping.

**Features:**

- A background image
- Company name: *Paradise Nursery*
- A short paragraph describing the company
- A **Get Started** button that links to the product listing page

---

### Product Listing Page

This page displays all available houseplants for purchase.

**Requirements:**

- At least **six houseplants**
- Organized into **three or more categories**
- Each plant includes:
  - Thumbnail image
  - Plant name
  - Price
  - **Add to Cart** button

**Header Features:**

- Shopping cart icon
- Dynamic number showing the **total items currently in the cart**
- Navigation to other pages

---

### Shopping Cart Page

The shopping cart page displays all items added by the user.

**Features:**

- List of all plants currently in the cart
- Thumbnail image and plant name
- Unit price
- Quantity controls:
  - Increase quantity
  - Decrease quantity
- Delete button to remove items
- Total number of plants in the cart
- Total cost of all items

**Actions available:**

- **Continue Shopping** button (returns to product listing)
- **Checkout** button

All updates to quantities should dynamically update:
- The shopping cart icon in the header
- The total number of items
- The total price

- Page navigation

These concepts will be useful for building more advanced applications in future projects.
